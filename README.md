# Password Strength and Policy Auditor

ECE 2260 Group Project

## Purpose
Build a Python tool that checks passwords and explains their weaknesses.

## Current Features
- Checks for at least 12 characters
- Checks uppercase and lowercase letters
- Checks numbers and symbols
- Shows which checks passed or failed

## Planned Features
- Common-password and dictionary-word detection
- Repeated-pattern detection
- Entropy estimate and strength rating
- NumPy analysis of sample passwords

## Run
py password_auditor.py

## Limitations
Passing the current checks does not guarantee a strong password.
Use made-up passwords for testing.
